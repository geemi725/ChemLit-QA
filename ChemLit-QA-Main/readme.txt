This directory contains 3 Question-Answer-Context (QAC) type datasets for RAG and finetuning tasks for Chemistry.

1. chemlit_qa_full_dataset.csv: Main dataset, contains 1025 entries evaluated by experts.

2. chemlit_qa_train_0.8_split.csv: This is a split from the main dataset for training tasks. Contains 820 entries.

3. chemlit_qa_test_0.2_split.csv: This is a test split from the main dataset for training purposes. Contains 205 entries.
